14 Production MCP Browser Tools

        
Comprehensive browser automation primitives designed for LLM token efficiency.

      


      

        

          
browser_navigate

          
Navigates to URL, history back/forward, or reloads active/new tabs.

        

        

          
browser_get_dom

          
Token-optimized accessibility snapshot with interactive refs (@e1, @e2).

        

        

          
browser_get_text

          
Extracts clean Markdown / plain text from active webpage or specific selector.

        

        

          
browser_click

          
Simulates realistic pointer and click events on elements by ref (@e1) or selector.

        

        

          
browser_type

          
Keyboard typing simulation into inputs/textareas with optional Enter key submission.

        

        

          
browser_press_key

          
Triggers keyboard interactions (Tab, Enter, Escape, Arrow keys).

        

        

          
browser_scroll

          
Smoothly scrolls viewports or elements up, down, top, bottom, or into view.

        

        

          
browser_screenshot

          
Captures high-resolution visual viewport snapshots for vision-capable models.

        

        

          
browser_list_tabs

          
Lists open Chrome tabs with IDs, titles, URLs, and active states.

        

        

          
browser_switch_tab

          
Activates and focuses a specific Chrome tab by tab ID.

        

        

          
browser_new_tab

          
Opens a new browser tab with an optional target URL.

        

        

          
browser_close_tab

          
Closes open tabs by tab ID.

        

        

          
browser_wait_for

          
Polls until a CSS selector is rendered and visible in DOM.

        

        

          
browser_evaluate

          
Evaluates custom JavaScript expression in page context (security gated).
